# 銃士＋魔彈客（繁體中文）v1.0.1

目標環境：Foundry VTT 13.351、D&D5e 5.3.3。採用指定網站目前的職業版本，並非舊版 Valda 銃士。這是資料彙編與有限輔助模組；不需要 Midi-QOL、DAE 或 DFreds。

## v1.0.1 說明文字更新

銃士與魔彈客的介紹、等級表及各項能力說明改用使用者提供的完整原文，保留簡體字句。能力說明及活動文字不再包含 FVTT 操作提示。六種基礎戰技與手指槍也已換成使用者提供的完整原文，包含手指槍譯注。

更新模組並由 GM 重新進入世界後，會自動更新本包彙編、世界物品及角色既有副本中仍與舊版相同的說明文字（包含場景內未連結角色的Token）。自行修改過的文字會保留；骰式、生命值、已消耗次數、等級及裝備不受影響。

若需重試文字更新，可用腳本巨集執行：

```js
await game.modules.get('valda-gunslinger-zh').api.migrateDescriptions();
```

## 直接透過 Foundry 安裝

在設定頁的「附加模組」→「安裝模組」，將以下網址貼入 Manifest URL：

```text
https://raw.githubusercontent.com/pk991233/valda-gunslinger-zh/main/module.json
```

安裝後進入世界並啟用模組。這是尚未完成世界內端到端驗證的初版，請先用測試角色試跑。

## 手動安裝

1. 解壓縮 ZIP，取得 `valda-gunslinger-zh` 資料夾。
2. 關閉 Foundry，將整個資料夾放進 Foundry 使用者資料目錄的 `Data/modules`。Windows 通常位於 `%LOCALAPPDATA%\FoundryVTT\Data\modules`；以實際使用者資料目錄為準。
3. 確認最後是 `Data/modules/valda-gunslinger-zh/module.json`，不要多套一層同名資料夾。
4. 重開 Foundry、進入世界，由 GM 在「管理模組」啟用「銃士與魔彈客（繁中）」。
5. 重新載入世界，按「建立彙編」。成功後會出現「銃士與魔彈客（繁中）」世界彙編，內含23個項目，以及「銃士：檢查與同步角色」巨集。
6. 將彙編中的「銃士 Gunslinger」拖到角色卡。完成生命值、熟練與精通選擇；升至3級後，再將「魔彈客 Spellslinger」拖入。之後照正常升級流程增加銃士等級。

先用一張測試角色卡試到3級，再用於正式角色。高等級角色也應經過系統的職業升級流程，單改總等級不會補齊特性。

如果初次選「稍後」，可建立「腳本」巨集，內容如下；它只補齊缺少的彙編項目，不會覆寫既有同ID項目。

```js
await game.modules.get('valda-gunslinger-zh').api.install();
```

## 使用範圍

| 項目 | 行為 |
|---|---|
| 職業／子職 | 原生職業與子職項目、等級特性授予、生命骰、豁免、技能、屬性提升／專長選擇 |
| 風險骰 | 2級4d8、6級5d8、10級5d10、14級6d10、18級6d12；短休／長休回滿 |
| 基礎戰技 | 全部放在「風險骰」項目內的活動，共用同一資源；不需要逐項再拖入 |
| 魔彈客戰技 | 自動連結角色自己的風險骰；剛拖入後若提示連結中，稍等再按 |
| 先攻 | 快速拔槍提供原生優勢效果，可與劣勢正常抵消 |
| 重擊 | 原生遠程武器攻擊套用19／18／17門檻；不影響近戰或一般法術攻擊 |
| 施法 | 智力、三分之一施法進度、準備法術數量；法術位由系統計算（兼職也交由系統） |
| 手指槍 | 戲法與武器分開；智力命中、2d6力場；總角色等級5／11／17級增加射程 |
| 斬盡殺絕 | 手指槍在銃士11級後自動加入智力傷害。其他遠程武器需手動配置，避免重複加值 |
| 極險決策 | 觸發後按風險骰中的「恢復1骰」，不自動判斷觸發事件 |
| 爆頭重置 | 勾選消耗3風險骰後重置爆頭使用次數；不重複支付爆頭本身的一次使用 |

## 需要手動完成

- 戰鬥風格：從你擁有的規則彙編加入一項。職業授予的是提示項目；近戰風格擴充至遠程武器的特殊適用條件請依原文與DM裁定。
- 起始裝備／金錢：原文A或B二選一，不自動加入。本包不提供實體槍械裝備表；手指槍則已包含。
- 軍用遠程熟練：進階授予系統內建的吹箭筒、手弩、重弩、長弓、滑膛槍及手槍；其他自訂軍用遠程武器請手動勾選熟練。未授予全部軍用近戰武器熟練。
- 精通：初始選2，4級及10級各增1；長休的更換與自訂槍械精通手動處理。手指槍原文有精通適用疑義，本包僅標示緩速，不擅自給予精通熟練。
- 法術：從你已有的法師法術列表挑選並拖入，將來源設為魔彈客、施法屬性設為智力。3級自選2道戲法，10級增至3道；手指槍是另外獲得。準備法術不是每天任意重選，須依原文的升級更換規則。
- 額外攻擊、法術射擊、18級額外戰技附贈動作：由玩家追蹤動作數量；若其他模組強制限制附贈動作，需手動處理額外那次動作。
- 咬緊牙關：擲出臨時HP後，使用聊天卡將其套用至自己；不要當一般治療。
- 盲射：感官與本回合結束的期限手動管理。翻滾閃避：自行移動Token及換彈。
- 擦掠彈、牛仔精神、千鈞一髮、魔法適性：活動會擲出所需數值；自行加到原結果，檢查每回合限制及觸發條件。
- 奧術射擊：命中手指槍後使用。若原攻擊重擊，按桌規及系統操作選擇其重擊傷害。
- 破臟彈／反魔法射擊：手動套用速度減半、攻擊劣勢、禁施法與維持專注劣勢；只作用於符合體型／觸發條件的目標，拔出彈頭即移除。
- 施法反制：DM判定本次攻擊適用的AC與防護，不會停用目標身上所有法術或刪除裝備。
- 死亡欺詐：確認不是立即死亡，先把HP改成1，再按恢復銃士等級HP；系統會消耗一次使用。
- 爆頭：只在符合條件的重擊時使用。HP≤100的死亡由DM處理；其他情況將追加傷害改為武器原類型並套用。活動擲出的10d10在死亡分支不用套用。
- 魔彈：先擲風險骰，把結果加到武器攻擊；命中時結算法術效果與武器正常傷害，不要再擲第二次法術攻擊。

## 檢查、停用與更新

選取一個Token，執行「銃士：檢查與同步角色」，可修正本包共享資源連結、更新手指槍射程，並私訊基本檢查結果。該檢查不會自動補給資源、升級角色或新增缺少的能力。

請保留模組啟用：停用後世界彙編與角色項目仍存在，但重擊門檻輔助、共享資源新連結、手指槍射程更新、恢復／重置按鈕失去模組支援。不要在停用時使用恢復／重置活動。

一般重複匯入只補缺項，不覆寫既有同ID項目。v1.0.1 的文字遷移會另行更新仍與舊版相同的說明文字。未修改既有世界、角色或其他模組檔案。更新前請保留自己的修改。

## 驗證狀態

資料欄位與事件介面依本機實際安裝的 D&D5e 5.3.3 原始碼核對；已完成JavaScript語法、資料參照、等級表、消耗連結與匯入重試邏輯測試。匯入器會先使用當前世界的Item模型驗證全部資料，通過才建立彙編。

尚未在實際運行的 FVTT 13.351 世界完成端到端拖曳／升級／擲骰測試，亦未驗證 Midi-QOL、Tidy5e 等第三方模組組合。因此這份是可供安裝測試的初版，不宣稱所有自動化完全相容。
